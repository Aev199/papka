# Исправления по проверке от 19.11.2026

База: `b46d2fc`, ветка `feat/native-gpui-foundation`.

## Исправлено

- Паспорт: полная модель хранит все строки и длинный текст. Сокращение до 400 символов и первых 60 строк применяется только при показе карточки; редактор получает все данные. У неизменённого блока сохраняется исходная JSON-структура, включая вложенные объекты, числа и null. Открытие и закрытие без правок не переписывает файл.
- Журнал: новые события показываются после 60-й записи; при редактировании доступен весь журнал. Просмотр выводит последние 12 событий.
- Чтение паспорта ограничено 2 МиБ в обоих API по реально прочитанным байтам. Слишком большая правка отклоняется до записи, прежний файл остаётся цел.
- Сравнение прекращается с объяснением и путём при недоступной подпапке, ошибке записи каталога, неподдерживаемой ссылке или отмене. Неполный обход больше не даёт результата «Папки совпадают». Убрано повторное чтение каталогов ради имён.
- Каждое сбойное задание переноса хранит собственные пути, цель, вид операции и политику конфликта. Следующая успешная операция не стирает возможность повтора. Совокупный отчёт учитывает несколько папок назначения.

## Найдено интерактивно и исправлено

- После Ctrl+Z у создания/копирования исчезнувший объект оставался выбранным в строке состояния. Отмена очищает выбранный путь, якорь и групповое выделение для путей, исчезнувших при отмене.
- После закрытия редактора карточки фокус оставался у скрытого поля: Escape и Ctrl+K переставали работать. Фокус возвращается в окно после сохранения, отмены, закрытия карточки и поля папки; переход между редакторами сохраняет фокус нового поля.
- В текстовых полях отсутствовали Ctrl+Home/End и выделение с Shift для Windows/Linux. Добавлены привязки только в контексте Input. Длинный редактор растёт до 12 строк, остальное прокручивается внутри.

Предположение о неактивируемой пустой панели исключено: повторная проверка настоящими событиями мыши показала, что активация работает; проблема была в способе передачи кликов инструментом проверки.
