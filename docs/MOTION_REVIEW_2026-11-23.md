# Ревью анимаций Papka — 23.11.2026

Проверена порция `1d6f5d3`: боковая панель, перестроение списка и Quick Look.

## Обнаружено и исправлено

- **Пустой кадр на больших картинках.** Наличие пути считалось готовностью
  предпросмотра, хотя `img` ещё декодировал файл. Теперь переход начинается
  после готовности того же GPUI asset, который использует `img`; до этого
  сохраняется старое содержимое. Ошибка декодирования становится сообщением.
- **Сброс масштаба старого кадра.** При начале запроса следующего файла
  прежний кадр немедленно возвращался к масштабу 1. Теперь поза сохраняется
  до готовности замены, а для исходящего кадра сохраняется отдельно.
- **Закрытие во время смены содержимого.** Общее состояние анимации стирало
  промежуточный кадр. Закрытие оболочки и переход содержимого теперь независимы.
  Повторный Пробел во время закрытия снова открывает просмотр.
- **Метки под фильтром.** Изменение метки обновляло список мгновенно:
  ревизия меток отсутствовала в условии запуска перестроения. Условие дополнено.

При проверке списка не обнаружено подтверждённых ошибок соответствия кликов
файлам и логического порядка выделения. Фоновые обновления метаданных сами
по себе по-прежнему не запускают анимацию, чтобы наблюдатель не вызывал мигание.

## Следующая порция

Реализована плавная геометрия и проявление подсказки стыковки вкладок.
Подпись показывает действие: разделение с указанной стороны или перенос.
При достижении лимита панелей подсказка показывает перенос. Геометрия
подсказки — только представление; действие определяется актуальным hit test.
Быстрая смена цели продолжает движение от текущих координат, отключённые
анимации применяются немедленно. Кадры запрашиваются только на время перехода.

Дальше: перемещение соседних вкладок при изменении позиции перетаскиваемой
вкладки и унификация оставшихся всплывающих поверхностей. Сначала — оценка
этой порции на Windows; Windows Shell/Office/PDF требуют отдельного прогона.

## Продолжение: перестановка вкладок

При наведении перетаскиваемой вкладки на полосу соседние вкладки плавно
освобождают место. Расчёт учитывает реальную ширину каждой вкладки,
середины неподвижных слотов и горизонтальную прокрутку. Промежуток
показывает окончательное место вставки; для перемещения внутри панели
индекс пересчитывается после удаления исходной вкладки.

При уходе с полосы и отмене вкладки возвращаются к исходным местам.
Отключённые анимации применяют геометрию сразу. Положение указателя
не зависит от анимированного содержимого, что предотвращает дрожание цели.
Отдельный модуль состояния содержит анимации, целевую позицию и тесты;
в Explorer новые флаги не добавлены.

Следующий шаг — оставшиеся всплывающие поверхности: единое короткое
появление и закрытие с корректной отменой, без перезапуска при обновлениях.

## Ревью вкладок и переходы всплывающих окон — 24.11.2026

Обнаружено: изменение числа вкладок при активном перетаскивании могло
оставить прежнюю цель вставки. При изменении одной из участвующих панелей
предпросмотр сбрасывается, активное перетаскивание отменяется до нового рендера.

Общий переход 120 мс подключён к контекстному меню, палитре команд,
переходу к папке, настройкам, окну «О программе», созданию файла/папки/проекта
и подтверждениям удаления/закрытия без сохранения. При закрытии сохраняется
последнее представление, его кнопки и ввод блокируются; действия выполняются
сразу, без задержки до завершения анимации. Большой список папок передаётся
для закрытия перемещением, без клонирования на каждом кадре.
Обновление содержимого не перезапускает появление; новый serial меню
запускает новое появление. Отключённые анимации применяются немедленно.
