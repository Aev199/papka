# Карточка проекта и паспорт объекта

Щелчок по имени проекта в начале строки вкладок открывает карточку
проекта **внутри панели**: она занимает место списка файлов. Повторный
щелчок, `Esc`, крестик или переход на любую вкладку возвращают папки.
Вторая панель при этом работает как обычно.

## Свои разделы

Раздел — это название и свободный текст. Разделы добавляются кнопкой
«Добавить раздел», правятся карандашом, поднимаются стрелкой и удаляются
корзиной (второй щелчок подтверждает). Карточка хранится в настройках
Papka вместе с проектом; в папки объекта ничего не пишется.

То, как строка написана, определяет, как она показана:

| Строка | Как показана |
|---|---|
| `Заказчик: ООО «Мост»` | поле: метка и значение в две колонки |
| `Z:\Объекты\044\ИГИ` или `\\сервер\папка` | ссылка: папка открывается в новой вкладке панели |
| `Модель: Z:\Объекты\044\model.txt` | поле со ссылкой: открывается папка файла, файл выделен |
| любая другая | строка текста |

Меткой считается короткий текст до двоеточия, за которым идёт пробел или
конец строки; «в 12:30» и адреса сайтов полями не становятся.

## Папки проекта

Список папок для быстрого перехода хранится в карточке и не зависит от
того, какие вкладки открыты. При первом открытии карточки в него попадают
вкладки проекта; дальше список ведёте вы:

- кнопка с папкой и плюсом у заголовка — добавить папку по пути (Enter);
- кнопка «+» — добавить все открытые сейчас вкладки проекта;
- в меню папки в списке файлов — «В папки проекта «…»», в меню пустого
  места — «Эту папку — в папки проекта «…»»;
- у строки (по наведению): домик — сделать папкой объекта, стрелка —
  выше, крестик — убрать из списка (папка на диске остаётся).

Щелчок по папке открывает её в новой вкладке.

## Разделы, которые ведёт Papka

- **Входящие** — то, что прислал Notch («В проект…»): снимки с
  подписью, тексты, ссылки на файлы. См. [INBOX.md](INBOX.md). По
  наведению: «В заметки», «Показать в папке», корзина — удалить запись
  (второй щелчок подтверждает; снимок и подпись уходят в Корзину через
  журнал, `Ctrl+Z` возвращает).
- **Паспорт объекта** — содержимое `object.json`, если он есть в одной из
  папок проекта или не выше пяти уровней над ней. Пока расчётные
  программы его не пишут, раздела в карточке нет. Пути к моделям и базам
  в паспорте — ссылки (относительные считаются от папки паспорта).
- **Последние изменения** — до 12 записей ленты Papka за 30 дней по
  папкам проекта.

Карточка обновляется сама: «Входящие» — каждые несколько секунд, паспорт
и изменения — примерно раз в 15 секунд, без мигания. Кнопки разделов
появляются при наведении; встроенные разделы скрываются значком глаза и
возвращаются строкой «Скрыто» внизу карточки.

## Правка разделов

Щелчок по тексту раздела (или карандаш) — правка прямо на месте:
заголовок и текст становятся полями, ничего не сдвигается. Enter в
заголовке переходит к тексту. «Готово» или `Esc` сохраняют, «Отмена»
возвращает как было (новый пустой раздел исчезает).

## Что Papka читает из `object.json`

Файл — объект JSON в UTF-8 (с BOM или без), не больше 2 МБ. Papka не
требует точной схемы: известные поля встают на свои места, остальное
показывается блоками в порядке файла.

| Поле (любое из имён) | Куда попадает |
|---|---|
| `name`, `title`, `object`, `название`, `объект` | заголовок паспорта |
| `updated`, `updated_at`, `modified`, `обновлено` | «обновлено …» |
| `updated_by`, `program`, `writer`, `программа` | там же, после даты |
| `warnings`, `alerts`, `предупреждения` | выделенные строки вверху |
| `journal`, `log`, `history`, `журнал` | «Журнал расчётов» |
| `schema`, `version`, `format`, `$schema` | не показывается |
| любое другое со значением-объектом | блок: строки «поле — значение» |
| любое другое со значением-списком | блок: строка на элемент |
| любое другое с простым значением | строка в блоке «Объект» |

Элемент списка называется по своему полю `name`, `kind`, `type`,
`program`, `id` или `no`. Предупреждения и записи журнала — строки или
объекты; объект выводится одной строкой из своих значений.

Заголовки известных блоков переводятся (`geology` — «Геология», `models` —
«Модели», `iterations` — «Итерации», `units` — «Единицы» и т. п.);
незнакомые имена показываются как написаны, с пробелами вместо `_`.
Писать имена блоков можно сразу по-русски.

Пометку «устарело» (расчёт выполнен по модели, которую потом изменили)
вычисляет библиотека паспорта и кладёт в `warnings` — Papka только
показывает её первой.

## Пример

```json
{
  "schema": 1,
  "name": "ЖК Остров",
  "updated": "05.11.2026",
  "updated_by": "SoilStiffness 1.8.2",
  "geology": {"file": "ostrov.sqlite", "revision": "14.10", "ige": 9, "boreholes": 23},
  "models": [
    {"kind": "ЛИРА", "file": "lira/ostrov.txt", "units": "м, кН", "modified": "03.11"},
    {"kind": "MIDAS", "file": "midas/ostrov.mec", "units": "мм, Н", "modified": "28.10"}
  ],
  "iterations": [{"no": 2, "text": "C1 ±6 % к №1, осадка 109 → 112 мм"}],
  "warnings": ["C1 iter2 считан по ЛИРА от 01.11, модель изменена 03.11 — устарело"],
  "journal": [{"date": "05.11", "program": "SoilStiffness", "text": "MIDAS → ЛИРА 2024, 3 предупреждения"}]
}
```
