## Исправления по ревью

1. Ctrl+P различает автоматическое выделение и выбор стрелками. При фоновом
   обновлении точный путь заменяет автоматический fuzzy-результат. Enter до
   окончания пробы направляется на введённый путь через прежнюю проверку
   навигации, а не подменяет его похожей папкой. Выбор стрелками и щелчком
   остаётся явным; новый запрос сбрасывает его.
2. Запуск отложенных сведений отделён от сброса выбора. Устаревший ответ
   освобождает слот и запускает сведения текущего поколения, сохраняя готовую
   миниатюру и состояние её декодирования.
3. Проверка необходимости кадров подсветки отмены перенесена в конец render,
   после создания эффекта. Отмена перестановки без изменения порядка тоже
   получает кадры затухания.

## Оставшийся порядок

1. Автоматическая проверка исправлений; тесты регрессий точного пути и гонки

   `UI_MOTION_2_ACCEPTANCE.md`, измерения относительно Beta 105 и полировка.
4. После приёмки — новая бета. Этот проход исправлений не запрашивает EXE.
