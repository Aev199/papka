# Papka и открытые исходники Atlas — 17.11.2026

Источник: github.com/neondeex/atlas-filemanager (один коммит от 12.11.2026,
версия 0.1.5). Раньше Atlas сверялся только по скриншотам и видео.

**Лицензия Atlas — AGPL-3.0-or-later.** Копировать или пересказывать близко к
тексту его код в Papka нельзя (иначе Papka тоже обязана стать AGPL). Можно
смотреть идеи и устройство и писать своё.

## Масштаб

| | Papka | Atlas |
|---|---|---|
| Строк Rust (без vendor) | ~25 тыс. | ~175 тыс. (UI 115 тыс.) |
| Тестов `#[test]` | ~290 | ~720 |
| GPUI | gpui-ce 0.2.2 с crates.io + патч Windows drop | свой форк gpui-ce + форк gpui-component (анимации, плавная прокрутка, кэш сцены) |
| Языки | русский | 10+ (rust-i18n) |
| Платформы | Windows | Windows, Linux-пакеты в разработке |
| Распространение | портативный ZIP + своё автообновление | Microsoft Store, Free/Premium |

## Что есть у Atlas и нет у Papka

- Виды: сетка, подробный, дерево; Papka — список, Миллер, плитки.
- Разделение панелей в любом направлении (дерево раскладки), у Papka — две панели.
- Поиск по всему тому через MFT/USN (`atlas-search-service`, `volume_index.rs`),
  нечёткий поиск nucleo, поиск по содержимому. У Papka — индекс SQLite папки
  и `notify`.
- Архивы как папки: ZIP, RAR, 7z, TAR (у Papka — zip).
- Конвертация файлов (ffmpeg, Pandoc, Opus) с радиальным меню.
- Облака через rclone, SMB/FTP/WebDAV в боковой панели.
- Приватные папки с паролем (vault), очистка диска и «Space Lens» по MFT.
- Расширения (манифест + sidecar-процессы), темы и пакеты значков VS Code,
  редактор тем, переназначение клавиш.
- Анимации на пружинах, стеклянные поверхности, отчёты о сбоях с символами.

## Что есть у Papka и нет у Atlas

- История файлов (только метаданные): кто, когда, комментарий, учёт версий
  `_v_1_6` и блок «Версии».
- Миниатюры и предпросмотр DWG без AutoCAD.
- Сравнение папок, проверка копий, журнал операций с восстановлением,
  поэтапное копирование без перезаписи.
- Проекты внутри панели, лента, метки, правила для сетевых путей (DFS/UNC).
- Повторный запрос списка при drop (работа с 7-Zip) — патч `gpui_ce_windows`.

## Что стоит взять как идеи (своей реализацией)

1. Единый конвейер переноса `validate → detect_conflicts → диалог → execute`
   с отчётом по каждому элементу — сверить с нашей очередью и диалогом замены.
2. Исключения для фоновых обходов (`scan_policy.rs`: Windows, ProgramData,
   приватные пути) — для индекса и наблюдателей.
3. Поиск по тому через USN Journal — давно в планах README; у Atlas видно, что
   это отдельный процесс-служба с правами.
4. Плавная прокрутка колёсиком и анимации панели сведений — у них сделаны
   патчами GPUI; для нас дорого (свой форк), брать только если очень нужно.
5. Нечёткий переход к папке (Ctrl+K) с ранжированием nucleo.
6. Восстановление после паники рабочих потоков и «отравленных» блокировок
   вместо закрытия приложения.
