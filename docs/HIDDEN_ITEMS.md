# Скрытые файлы и папки

- Ctrl+H показывает/скрывает скрытые файлы и папки. Ctrl+. остаётся синонимом.
- Настройки (Ctrl+,): «Показывать скрытые файлы и папки», рядом указан Ctrl+H.
- Тот же переключатель доступен через значок глаза внизу и контекстное меню папки.
- Быстрый переключатель сохраняет только show_hidden в SQLite, сохраняя остальные
  настройки. После перезапуска состояние восстанавливается.
- На Windows используется атрибут Hidden, для файлов и папок одинаково;
  на других платформах — имена, начинающиеся с точки.

Проверить показ/скрытие в списке, колонках и миниатюрах; два сочетания клавиш;
переключение значком глаза и через настройки; восстановление после перезапуска.
Автоматические тесты проверяют реальные Hidden-атрибуты Windows у файла и папки,
фильтрацию, сохранение состояния и отсутствие сброса остальных настроек.
