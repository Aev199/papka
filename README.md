# Papka

Файловый менеджер для Windows на Rust + GPUI: вкладки и панели, колонки,
быстрый поиск, безопасные операции с отменой, предпросмотр и история
изменений папок. Интерфейс — на русском. Портативный: один `Papka.exe`,
установка не нужна.

> **Статус: бета.** Сборки выходят из ветки `feat/native-gpui-foundation`
> через ручной запуск GitHub Actions. EXE не подписан сертификатом —
> Windows SmartScreen при первом запуске показывает предупреждение.

## Что умеет

- **Панели и вкладки.** Окно делится вправо и вниз, у каждой панели свои
  вкладки; вид — список, колонки или миниатюры (`Ctrl+1/2/3`). Вкладки,
  панели и вид сохраняются между запусками; наборы вкладок сохраняются
  как проекты.
- **Операции без потерь.** Копирование и перенос никогда не перезаписывают
  молча: при совпадении имён — диалог «пропустить / оставить оба /
  заменить». Удаление — в Корзину. `Ctrl+Z` отменяет переименование,
  перенос, копирование, создание и удаление, если файл с тех пор не
  менялся. Каждая операция записывается в журнал до изменения диска.
- **Очередь переносов.** Копирование или перенос, запрошенные во время
  другой операции, встают в очередь и запускаются по порядку. Ход виден
  в небольшом окне в углу: пауза, отмена, а после — полный текст каждой
  ошибки и «Повторить сбойные».
- **Действия Проводника в меню.** Под своими командами контекстное меню
  показывает действия Windows для файла: «Открыть с помощью»,
  «Отправить», архиватор, «Свойства» и другие установленные программы.
- **Поиск.** Набор букв фильтрует текущую папку; `Ctrl+F` ищет во
  вложенных папках с фильтрами по типу, дате, размеру и глубине.
- **Сведения и предпросмотр.** Панель сведений (`Ctrl+I`), быстрый
  просмотр по пробелу, миниатюры изображений, PDF, Office и DWG. Архивы
  zip и 7z открываются как папки.
- **Карточка проекта.** Щелчок по имени проекта в строке вкладок
  открывает страницу проекта: паспорт объекта (`object.json` расчётных
  программ — предупреждения, модели, итерации, журнал), папки проекта и
  последние изменения. См. [docs/PROJECT_CARD.md](docs/PROJECT_CARD.md).
- **Версии документов.** Файлы вида `имя_v_1_6` собираются в одну строку;
  шаблоны версий настраиваются.
- **История изменений.** Лента изменений открытых папок. Хранятся только
  метаданные: кто, когда, что произошло, и ваш комментарий.
- **Прочее:** сравнение и синхронизация двух папок, массовое
  переименование, цветные метки, размеры папок, палитра команд
  (`Ctrl+K`), светлая и тёмная темы.

**Содержимое файлов Papka никогда не сохраняет**: нет ни копий старых
версий, ни дельт. История и журнал — только пути, время и тип действия.

## Основные клавиши

| Клавиши | Действие |
|---|---|
| `→` `←` | в колонках: войти в папку и выйти из неё |
| `Ctrl+1` `Ctrl+2` `Ctrl+3` | список, колонки, миниатюры |
| `Alt+←` `Alt+→` | назад и вперёд |
| `Ctrl+L` | ввести путь |
| `Ctrl+Shift+S`, `Ctrl+Alt+S` | разделить окно вправо, вниз |
| `Tab` | перейти в другую панель |
| `Ctrl+T`, `Ctrl+W` | новая вкладка, закрыть вкладку |
| `Alt+C`, `Alt+M` | копировать, перенести выбранное в другую панель |
| `F2`, `Del`, `Ctrl+Z` | переименовать, в Корзину, отменить |
| `Ctrl+N`, `Ctrl+Shift+N` | новый файл, новая папка |
| `Ctrl+F` | поиск во вложенных папках |
| `Ctrl+I`, пробел | сведения о файле, быстрый просмотр |
| `Ctrl+K` | все команды и их клавиши |

Полный список — в палитре команд и на стартовом экране («?» вверху справа).

## Данные программы

`%LOCALAPPDATA%\Papka\`: настройки и рабочие пространства, журнал
операций, история изменений, поисковый индекс, кэш миниатюр. Удаление
этой папки сбрасывает настройки; файлы пользователя она не содержит.

## Устройство

- `crates/core` — логика без интерфейса: операции, журнал, история,
  поиск, обновления. Покрыта тестами.
- `crates/desktop` — окно на GPUI (`gpui-ce 0.2.2`).
- `crates/cli` — `fmctl`, утилита для проверки ядра из терминала.
- `vendor/gpui_ce_windows` — крейт GPUI с одной правкой для
  перетаскивания из архиваторов (см. его `PAPKA.md`).

Сборка и выпуск — [docs/BUILD.md](docs/BUILD.md) и
[docs/UPDATES.md](docs/UPDATES.md). Ручная проверка на Windows —
[docs/SMOKE_TEST.md](docs/SMOKE_TEST.md). Правила работы над кодом —
[CLAUDE.md](CLAUDE.md).

## Чего нет и не планируется

Облачные диски, FTP/SFTP и плагины.
