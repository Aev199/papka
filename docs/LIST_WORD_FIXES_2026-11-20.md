# Список, выделение и просмотр Word — 20.11.2026

- Часы появления списка перенесены из временного UI-элемента в состояние панели. Перечитывание папки больше не запускает появление заново; загрузка и пустые папки учитываются отдельно от первого показа строк.
- Цвет имени, метаданных, значков и значков версий меняется по положению движущегося выделения. Быстрые повторные стрелки продолжают движение из уже показанного положения; щелчок мышью прекращает этот переход.
- Ctrl+щелчок согласует набор выделенных файлов с активным выбранным файлом. Удалённый из набора файл больше не остаётся выделенным через одиночный выбор; снятие выделения с последнего элемента оставляет пустой выбор. Ctrl/Shift+щелчки не принимаются за открывающий двойной щелчок.
- Пробел открывает встроенный текстовый просмотр `.doc` (Word 97–2003) и `.docx`, включая кириллицу и абзацы. Оформление, рисунки и расположение страниц этим режимом не воспроизводятся. Кнопка подробного просмотра через обработчик Windows сохранена. Пароль, повреждения и ограничения размера дают сообщение; исходник не изменяется, извлечённый текст не сохраняется на диск.

Проверено: 353 теста workspace, Windows GNU check всех целей, отдельные тесты layout (20) и palette (6), проверки привязок интерфейса и отмены перетаскивания. В нативном Linux GUI проверены светлая тема, выбор/снятие выбора в списке и плитках, Ctrl+A и снятие после прокрутки, снятие последнего элемента, F5/переходы между папками, настоящий `simple.doc` из тестовых данных Apache POI и кириллический DOCX. Переходы длительностью 100–140 мс дополнительно проверены тестами управляемого состояния; окончательную плавность на Windows нужно оценить в Windows-сборке. Подробный COM-просмотр Windows здесь не запускался.

Чтение бинарного DOC следует [MS-DOC 2.4.1](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-doc/01d5d8c4-cf9c-4ef9-80fd-439e763cfe01): FIB, CLX, таблица фрагментов, UTF-16 и сжатый текст. Тесты проверяют порядок фрагментов независимо от физического расположения, оба Table-потока, поля, исключение текста вне основной части, шифрование, повреждения и лимиты. DOCX читается из основной части ZIP без DTD и внешних сущностей.
