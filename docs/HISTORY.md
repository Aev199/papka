# История изменений файлов

Papka записывает события из видимых папок, пока программа запущена. Наблюдение нерекурсивное: вложенная папка начинает наблюдаться, когда открыта в панели (включая колонки). Лента родительской папки объединяет уже записанные события её подпапок. Это не полный аудит диска и не система резервного копирования.

Для локальных папок используются уведомления файловой системы; сетевые папки перечитываются примерно раз в пять секунд. Изменение определяется по размеру и времени модификации. Сохраняются путь, тип события, время, метаданные, отметка наблюдателя и добавленные пользователем комментарии. Содержимое файлов не читается для сравнения и не хранится. Быстрые повторные уведомления объединяются; переименование может отображаться как удаление старого и появление нового имени.

База: `%LOCALAPPDATA%\Papka\native-history.sqlite3`. Это локальная база текущего пользователя; файлы проекта не дополняются журналом. При миграции старой установки временно может использоваться каталог `Filemanager` вместо `Papka`. База сохраняется между запусками; фильтры «Сегодня / Неделя / Месяц / Всё» ограничивают показ, а не срок хранения.

Отключение: **Ctrl+, → Файлы → Записывать историю изменений файлов → снять флажок → Сохранить**. Настройка сохраняется после перезапуска. Новые события и обновления метаданных для истории останавливаются; существующие записи остаются доступными. Автообновление списка файлов продолжает работать. Наблюдения, уже полученные фоновыми задачами, также проверяют общий запрет записи.

Журнал безопасного выполнения файловых операций и отмена Ctrl+Z работают отдельно: отключение ленты не отключает защиту копирования, переноса и удаления.
